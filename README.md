# BenC2514 Fusion Scripts

*To Install: Save folder to fusion scripts folder. Add to fusion by going to utilities->add-ins ->scripts & add-ins ->my scripts ->+*

## STL Exporter (Numerical)
- Exports stl files with a single numerical variation, handy for differentiating between multiple identical parts
- Create the text you want to alter in its own sketch in the root part. Reference the sketch name in the gui when prompted 
1) Add Sketch Name from Changing Sketch (Should be in Root)
2) Choose Starting Number
3) Choose Finish Number
4) Select export destination

## STL Exporter (CSV)
- Exports stl files taking single-line csv input
- Create the text you want to alter in its own sketch in the root part then reference the sketch name in the gui when prompted 
1) Open .csv file
2) Select Save Location
3) Enter Name of Sketch 

## STL Exporter (Parameter)
- Exports STL files whilst changing parameter size and text
1) Select Starting Parameter Size
2) Select Finish Parameter Size
3) Select Step Size (i.e. 10 would increment size by 10mm)
4) Select Parameter Name
5) Enter Name of Sketch
6) Select Output Path Location
